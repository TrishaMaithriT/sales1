About this Project

SalesCast — AI Sales Prediction System

A complete machine learning project built with Python, Flask, and Linear Regression.

Project Overview

What is SalesCast?

SalesCast is a complete end-to-end Machine Learning web application that allows businesses to upload historical sales data and receive accurate future sales predictions using the Linear Regression algorithm.

The system uses time-series feature engineering — including lag values and rolling averages — to capture sales trends and seasonality patterns in your data.

Project Objectives

Enable non-technical users to run ML forecasting without coding
Provide accurate sales predictions using proven ML algorithms
Visualise model performance with interactive charts
Export forecast reports in CSV format
Deliver a professional multi-page web interface
ML Pipeline

How the Machine Learning Works

A complete feature engineering and model training pipeline under the hood.

1

Data Ingestion

CSV is parsed, column headers are auto-detected (date + sales), and values are sorted chronologically.

2

Feature Engineering

5 features are built per record: time index, Lag-1, Lag-2, Lag-3, and Rolling Mean (3 periods).

3

Scaling & Splitting

MinMaxScaler normalises values to [0,1]. Data is split 80% train / 20% test for unbiased evaluation.

4

Model Training

Scikit-learn LinearRegression is fitted on the training set. Predictions are inverse-scaled back to original units.

5

Forecasting

Future months are predicted iteratively — each prediction becomes a lag input for the next month.
